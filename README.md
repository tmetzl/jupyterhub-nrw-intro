# Start in JupyterHub.nrw

Material zur Session 1 "Start in JupyterHub.nrw" beim JupyterHub.nrw Tag.
Die Session richtet sich an Anfängerinnen und Anfänger ohne Vorkenntnisse.

**Speaker:** Tim Metzler, Hochschule Bonn-Rhein-Sieg

## Was ist JupyterHub.nrw?

JupyterHub.nrw stellt Hochschulen in Nordrhein-Westfalen JupyterHubs für Forschung und Lehre bereit.
Man meldet sich mit dem Hochschul-Account an, startet im Browser einen eigenen Server und arbeitet sofort in Jupyter Notebooks. Auf dem eigenen Rechner muss nichts installiert werden.

## Wie bekomme ich das Material?

Alle Notebooks liegen in diesem Repository. Im Workshop holst du sie mit einem Klick auf diesen Link in deinen Server:

> Link folgt (nbgitpuller)

Danach öffnet sich `00_start.ipynb` mit einer Übersicht aller Materialien. Im Dateibrowser links liegt alles im Ordner `jupyterhub-nrw-tag`.

## Welches Notebook zuerst?

| Datei | Inhalt |
|---|---|
| `00_start.ipynb` | Übersicht mit Links zu allen Notebooks |
| `01_erste_schritte.ipynb` | Zellen ausführen, Markdown und Code, Kernel, Dateibrowser |
| `02_daten.ipynb` | Einen offenen Datensatz einlesen, filtern und plotten |
| `zugaben/` | Für Schnelle: Statistik mit R, eine kleine Textanalyse, eine Kurvendiskussion mit SymPy |

Beginne mit `01_erste_schritte.ipynb`. Die Notebooks sind so gebaut, dass du den Code nicht selbst schreiben musst. Du führst ihn aus, änderst einzelne Werte und schaust, was passiert.

## Roter Faden: Reproduzierbarkeit

Code, Daten, Text und Ergebnis stehen in einem Dokument. Alle arbeiten in derselben Umgebung. Wer ein Notebook weitergibt, gibt damit auch das Ergebnis weiter: "Restart & Run All" genügt.
